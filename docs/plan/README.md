# plan

実装単位の計画と受入証跡を置く場所。`{Component}/{YYYYMMDD}_{topic}.md` の形式でファイルを置く（例: `docs/plan/Template/20260807_template-design.md`）。

1 ファイルが 1 つの実装単位（コンポーネント × 話題）に対応する。日付は「いつ書かれた計画か」を示すためのものであり、`docs/adr/` の連番のような相互参照の識別子ではない。

template clone後の初期判断フローと質問の正本は [Template/20260828_bootstrap-template.md](Template/20260828_bootstrap-template.md)。
